## Readiness findings

1. **High. Node coverage can pass with inaccurate direct-content boundaries.** The inventory comparison preserves a detected heading's parent and subtree, but excludes `direct_end_line`. The range check only guards against exceeding the whole subtree. A temporary probe extended a parent's direct-content endpoint to the end of its subtree and received `coverage_and_evidence_locations_valid`. The same bounds admit shortening the span without a registered child. Manually registered siblings can also overlap because the validator checks only each child's inclusion in its parent. Derive the expected direct endpoint from the first child, or the subtree endpoint for a leaf. Check sibling order and disjointness after registering manual divisions. [Inventory boundary checks](../.agents/skills/thesis-structure/scripts/structure.py#L94)
2. **Medium. Evidence can resolve without anchoring to the node or mapping.** Replacing every review's citations with line 1 of the appropriate documents passed even for leaf sections and mappings elsewhere. A reference review marked `unresolved` could name a target while citing reference evidence only, although the contract asks for target coverage when mapped. Require a local anchor for each reviewed node and evidence for mapped targets, with a documented exception where an inapplicability or unresolved judgment explicitly depends on context elsewhere. Keep complementary contextual citations permissible. [Evidence validation](../.agents/skills/thesis-structure/scripts/structure.py#L112) · [Mapping validation](../.agents/skills/thesis-structure/scripts/structure.py#L155) · [Evaluation contract](../.agents/skills/thesis-structure/references/evaluation.md#save-the-assessment)
3. **Medium. Dependency links can contradict assessments or close unrelated findings.** A dependency between the root and Introduction passed with an accepted finding for an unrelated nested section as its sole finding. Changing that dependency to `supported` also passed, with the finding still accepted and the affected node marked `sufficient`. The same record passed with `[null]` as its omission search record. Require dependency links to concern an endpoint and supported dependencies to carry only rejected findings. Check that live findings are reconciled with affected target reviews or their explicitly related dependencies. Require substantive nonempty search and missing-evidence entries where the contract calls for them. [Finding validation](../.agents/skills/thesis-structure/scripts/structure.py#L127) · [Dependency validation](../.agents/skills/thesis-structure/scripts/structure.py#L180)
